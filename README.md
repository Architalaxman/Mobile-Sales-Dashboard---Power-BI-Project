# 📊 Mobile Sales Dashboard - Power BI Project

## 📌 Project Overview
This project presents an interactive **Mobile Sales Dashboard** built using Power BI.  
It provides deep insights into sales performance, customer behavior, and product trends.

The dashboard helps in understanding:
- Sales distribution
- Revenue growth
- Product performance
- Customer purchasing patterns

---

## 🎯 Objectives
- Analyze mobile sales data effectively
- Identify top-performing products
- Track revenue trends over time
- Provide actionable business insights

---

## 📂 Dataset Features
The dataset includes:
- Product details
- Sales amount
- Quantity sold
- Customer information
- Date of transactions
- Region/Location data

---

## 📊 Dashboard Insights
Key insights covered:
- 📈 Total Sales & Revenue Trends
- 🏆 Top Selling Mobile Brands
- 📍 Region-wise Sales Analysis
- 👥 Customer Segmentation
- 📦 Product Category Performance

---

## 🛠️ Tools & Technologies Used
- Power BI
- Power Query (Data Cleaning & Transformation)
- DAX (Data Analysis Expressions)

---

## 🚀 Features
- Interactive filters and slicers
- Dynamic visuals and charts
- Clean and user-friendly design
- Drill-down analysis capability
